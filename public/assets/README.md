# Gharana image library

Existing working assets remain in their original locations. New final images can be added to the structure below; update `src/data/images.ts` when a new file replaces a temporary source.

## Hero
- `hero/hero-main.webp` - 16:9 or wider, minimum 1920px wide
- `hero/hero-product-pack.webp` - transparent WebP or PNG, 1:1
- `hero/hero-floating-makhana-01.webp` - transparent WebP or PNG
- `hero/hero-floating-makhana-02.webp` - transparent WebP or PNG
